# Baselines de Performance

Este directorio contiene baselines históricos de performance del sitio.

## Cómo comparar

Cada baseline tiene:
- `reporte.md` — análisis completo
- `image-formats.csv` — tabla de AVIF/WebP/JPEG

Para comparar con el estado actual:
1. Generar nuevo baseline con el mismo método
2. Diffear CSVs y reports
